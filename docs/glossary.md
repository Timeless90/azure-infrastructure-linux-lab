# Glossar

| Begriff | Bedeutung im Kurs |
|---|---|
| Absolute/relative path | Pfad ab `/` bzw. ab aktuellem Arbeitsverzeichnis |
| Process / Signal | laufendes Programm / Nachricht zur Prozesssteuerung |
| systemd unit | deklarierte Betriebsdefinition, z. B. Service |
| Listener / Bind | Socket, der Verbindungen annimmt / gewählte lokale Adresse |
| Loopback | nur auf dem jeweiligen Host/Namespace erreichbar, IPv4 127.0.0.0/8 |
| CIDR | Präfixnotation, z. B. /24 = 24 Netzbits |
| Gateway / Route | nächster Router / Regel zur Auswahl des Weiterleitungswegs |
| TCP / UDP | verbindungsorientierter Bytestrom / unabhängige Datagramme |
| DNS / FQDN | Namensauflösung / vollständiger DNS-Name |
| NAT / SNAT | Adressübersetzung / Übersetzung der Quelladresse |
| NSG / UDR | Azure Network Security Group / User Defined Route |
| Private Endpoint | private NIC als Zugang zu konkreter Azure-Service-Subresource |
| Service Endpoint | VNet-Subnetzidentität für den öffentlichen Dienstendpunkt |
| TLS / SNI / SAN | Transportverschlüsselung / gesendeter Servername / Zertifikatsnamen |
| Entra ID / RBAC | Identitätsanbieter / rollenbasierte Berechtigungen am Scope |
| Managed Identity | Azure-verwaltete Workload-Identität ohne von dir verwaltetes Passwort |
| Management/Data Plane | Ressourcen verwalten / Dienstinhalte benutzen |
| IaC / Bicep | Infrastructure as Code / deklarative Azure-Ressourcensprache |
| Replica / Revision | laufende ACA-Instanz / unveränderlicher Konfigurationsstand |
| Namespace | isolierte Sicht, z. B. auf Container-Netzwerkinterfaces |
| Measurement point | Ort der Messung; Ergebnisse gelten zunächst nur dort |
