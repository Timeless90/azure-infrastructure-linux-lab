# Herkunft und Lizenzgrenzen

Alle Kurskapitel, Apps, Tests, Bicep-/Shell-Beispiele und Fehlerabläufe wurden für dieses Repository eigenständig formuliert. Keine fremden Kurskapitel, Grafiken, Templates oder Binärdateien werden mitgeliefert. Normale Befehls-/API-Bezeichner sind verwendet, keine größeren Textübernahmen. Ein public Repository erhält dadurch **nicht automatisch eine Open-Source-Lizenz**; für das Gesamtwerk wird hier keine solche Lizenz vergeben. Fremde Software unterliegt ihren eigenen Bedingungen.
